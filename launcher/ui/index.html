Warning
Steam Deck players: the "Instant character pop-in" patch below is known to hang the GPU and crash the whole desktop session on Steam Deck's AMD hardware — this reproduces identically whether you're on SteamOS or Steam Deck's own Windows dual-boot, so it isn't a one-off fluke. Leave it OFF unless you're specifically testing it and are prepared for a hard crash (save your game and close other work first). It's expected to work fine on most other GPUs/PCs — this is a known, actively investigated compatibility issue, not something you're doing wrong.

PERFORMANCE CAPTURE

Records which parts of the game are actually expensive: how many draw calls each frame and which game routine issues them, how many shader variants get built, and where frame time goes. Used to decide what to optimise next. It slows the game slightly and writes an extra log, so leave it off for normal play.

How
Arm it, launch the game, play the scene you care about for a minute or two, then quit the game normally — force-killing it loses the data. Then create a support bundle below; the capture is included automatically.

SUPPORT BUNDLE

Packs your recent session logs, performance samples, system info and settings into a single zip you can attach to a GitHub issue. It contains no save data and no game content, and nothing is uploaded automatically.

ABOUT

The Simpsons Game — Recompiled is a fan-made static recompilation: the original Xbox 360 game code is translated ahead-of-time into a native executable for your machine, rather than emulated instruction-by-instruction at runtime — running against a Xenia-derived GPU/kernel emulation layer (the ReXGlue SDK).

Platform status

• Linux / Steam Deck — playable: menus, saves, video, full gameplay.
• Windows — experimental, builds and boots via CI; shares the same GPU compatibility caveat noted in the Patches tab on Steam Deck's own hardware.
• Android — planned, not started.

Credits

• Static recompilation approach in the style of XenonRecomp.
• GPU/kernel emulation via the ReXGlue SDK, derived from Xenia, the Xbox 360 emulator.
• Uses SDL3, Dear ImGui, glslang/SPIRV-Tools, FFmpeg, spdlog, fmt, and the Tracy profiler, each under their own open-source licenses.
