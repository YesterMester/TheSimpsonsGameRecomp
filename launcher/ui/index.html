Quality

How many pixels the game draws. 3× is a true 4K picture; higher looks sharper and thin details like wires stay visible, but costs GPU time. Restart needed.
At 2× or 3×, shadows at the original resolution look almost the same and save about 0.7 ms per frame on the Steam Deck. No effect at 1×. Restart needed.
How the picture is scaled to your screen. Bilinear adds no sharpening. FSR 1 gives the crispest picture on 1080p and larger monitors. Restart needed.

Frame rate

The game shipped at 30 FPS, and some sections misbehave above it — known: random deaths at the dam in "Lisa the Tree Hugger" at 60. Switch to 30 for that part if it bites. The game cannot run faster than 60, so 90 and 120 only make frame pacing less even. Menus always run at 30, as on the console. Restart needed.

Keyboard & mouse

The game takes the mouse while its window is active (Alt+Tab lets go), and a controller keeps working alongside. In the game, F1 shows these controls.

Performance capture

Records which parts of the game are actually expensive: how many draw calls each frame and which game routine issues them, how many shader variants get built, and where frame time goes. Used to decide what to optimise next. It slows the game slightly and writes an extra log, so leave it off for normal play.

How
Arm it, launch the game, play the scene you care about for a minute or two, then quit the game normally — force-killing it loses the data. Then create a support bundle below; the capture is included automatically.

Support bundle

Packs your recent session logs, performance samples, system info and settings into a single zip you can attach to a GitHub issue. It contains no save data and no game content, and nothing is uploaded automatically.

About

The Simpsons Game — Recompiled is a fan-made static recompilation: the original Xbox 360 game code is translated ahead-of-time into a native executable for your machine, rather than emulated instruction-by-instruction at runtime — running against a Xenia-derived GPU/kernel layer (the ReXGlue SDK).

Platform status

• Linux / Steam Deck — playable: menus, saves, video, full gameplay.
• Windows — playable, less tested than Linux.
• Android — planned.

Credits

• Static recompilation approach in the style of XenonRecomp.
• GPU/kernel emulation via the ReXGlue SDK, derived from Xenia, the Xbox 360 emulator.
• Uses SDL3, Dear ImGui, glslang/SPIRV-Tools, FFmpeg, spdlog, fmt, and the Tracy profiler, each under their own open-source licenses.
